# spartanZ gaming
### PC Building and Gaming Hardware Store

## Project Overview

**spartanZ gaming** is a multi-page website for a gaming hardware store specializing in PC components and custom gaming PC builds.

The website is designed for gamers and PC enthusiasts who want to explore gaming hardware, browse featured PC builds, learn about different components, and request custom-built gaming computers.

## Project Theme

PC Building and Gaming Hardware Store – spartanZ gaming

## Development Approach

**Route B – Design from Scratch**

The website will be developed using HTML5 and CSS3 without external frameworks or libraries.

Each page will have its own CSS stylesheet, while a consistent navigation bar will be maintained throughout the website.

The project will be version-controlled using Git and hosted on GitHub.

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- Visual Studio Code

## Website Pages

### Assignment 1

1. **Home:** Introduction to spartanZ gaming, featured gaming PCs, and store highlights.
2. **Media and Info:** Gaming hardware information, component details, images, and multimedia content.
3. **Register:** Registration form for customers.

### Assignment 2

4. **Services:** Custom PC building, hardware upgrades, and related services.
5. **Portfolio:** Showcase of gaming PC builds and completed projects.
6. **Contact:** Contact information and customer inquiry form.

## Project Structure

The project will use separate HTML and CSS files for each page, with shared navigation across the website.
